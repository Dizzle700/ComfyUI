Ваши следующие шаги (пошагово):
Шаг 1. Создать Network Volume в консоли RunPod
Зайдите в RunPod Console → Storage → Network Volumes.
Нажмите New Network Volume:
Name: krea2-volume
Data Center: Выберите любой датацентр с наличием RTX 4090/5090 (например, EU-RO-1 или US-CA-1).
Size: 30 – 50 GB (это стоит ~$2–$3.5 в месяц).
Шаг 2. Загрузить модели на Network Volume (один раз)
Чтобы модели Krea-2 оказались на Network Volume:

Запустите в том же датацентре любой временный дешевый Pod (можно даже CPU-под или дешевый GPU), выбрав в расширенных настройках созданный Network Volume (он смонтируется в /workspace).
В терминале пода выполните:
bash
git clone --depth 1 https://github.com/Dizzle700/ComfyUI.git /workspace/repo
bash /workspace/repo/serverless/prepare_network_volume.sh --target /workspace
Скрипт скачает веса Krea-2 Turbo, Qwen3-VL, VAE и LoRA в нужные папки (models/diffusion_models, models/text_encoders, и т.д.).
После окончания скачивания удалите временный Pod — модели останутся на Network Volume навсегда.
Шаг 3. Создать Serverless Endpoint
Перейдите в RunPod Console → Serverless → Endpoints и нажмите + New Endpoint.
Задайте настройки:
Endpoint Name: krea2-serverless
Container Image: runpod/worker-comfyui:latest-base
GPU: Выберите RTX 4090 (24 GB) или RTX 5090 (32 GB).
Active Workers: 0 (чтобы воркер отключался и не тратил деньги в простое).
Max Workers: 1 или 2.
Idle Timeout: 5 сек.
FlashBoot: Enabled.
Network Volume: Выберите ваш krea2-volume.
Нажмите Deploy и скопируйте полученный Endpoint ID (например, v2-abc123xyz).
Шаг 4. Первая генерация!
Когда эндпоинт готов, запускаем генерацию с вашего компьютера:

bash
python3 serverless/test_client.py \
    --endpoint-id ВАШ_ENDPOINT_ID \
    --api-key ВАШ_RUNPOD_API_KEY \
    --prompt "A stunning cyberpunk samurai in neon rain, 8k resolution, photorealistic" \
    --sync
Готовая картинка автоматически скачается в папку 

serverless/output/
